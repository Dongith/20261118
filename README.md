A deterministic Python program that draws a newspaper-style front page summing up Wednesday 18 November 2026 world news. The lead story covers Trump landing in China as Xi and Putin prepare a rare trilateral summit, with six more stories — the Democrats taking the US Senate, Iran's drone strikes on Gulf states, the Congo Ebola outbreak, Voyager 1 reaching one light-day, a Russian military plane crash, and Gaza's winter cold — laid out in a two-column grid. It renders a clean 1024x1024 PNG on warm off-white paper using only the Python standard library and Pillow, with no network access and byte-identical output on every run.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024).
